# Ruthwik Reddy Sunketa - Academic Portfolio

This is my personal academic portfolio website showcasing my research, publications, and educational background as a Computer Engineering PhD student at Arizona State University.

## About

This portfolio is built using [DevsCard](https://github.com/KonradSzwarc/devscard), a template for creating developer/academic resumes.

**Forked from:** [KonradSzwarc/devscard](https://github.com/KonradSzwarc/devscard)

## Features

- Built with [Astro](https://astro.build/) - Modern static site generator
- TypeScript for type-safe data configuration
- Tailwind CSS for styling
- Responsive design for mobile and desktop
- PDF generation for downloadable CV
- GitHub Pages deployment

## Structure

```
src/
├── data/
│   ├── config.ts          # Site metadata and configuration
│   └── sections/          # Section-specific data (education, experience, publications, skills)
├── assets/                # Images and static assets
└── components/            # Reusable UI components
```

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Run all checks
npm run check
```

## Deployment

This site is deployed to GitHub Pages. Push to the `main` branch to trigger automatic deployment.
